# Sistema de gestión de una clínica veterinaria

Actividad del tema 8 de Ingeniería del Software. El equipo simula el seguimiento de una primera entrega que permite a recepción registrar titulares y mascotas y gestionar citas. El personal veterinario consulta el historial de cada animal y añade visitas.

## Equipo

| Integrante | Funciones en esta práctica |
| --- | --- |
| Respuesto1 | Coordinación del proyecto y pruebas de calidad |
| mingxu960-droid | Análisis funcional, experiencia de usuario y frontend |
| markuus04 | Backend, base de datos, DevOps y permisos |

## Seguimiento

El [tablero de la primera entrega](https://github.com/users/Respuesto1/projects/1/views/1) organiza las [ocho Issues](https://github.com/Respuesto1/clinica-veterinaria-is/issues?q=is%3Aissue) en **Pendiente**, **En desarrollo** y **Finalizado**. Cada ficha identifica su responsable, su prioridad y los criterios para darla por terminada.

La [agenda de recepción (#5)](https://github.com/Respuesto1/clinica-veterinaria-is/issues/5) necesita el [servicio de reservas (#4)](https://github.com/Respuesto1/clinica-veterinaria-is/issues/4) para probar la confirmación de una cita. El [comentario de bloqueo](https://github.com/Respuesto1/clinica-veterinaria-is/issues/5#issuecomment-7110921438) documenta qué puede avanzar mientras tanto.

La [Discussion sobre reservas simultáneas](https://github.com/Respuesto1/clinica-veterinaria-is/discussions/9) compara dos alternativas y recoge la respuesta aceptada. La [Issue de pruebas (#7)](https://github.com/Respuesto1/clinica-veterinaria-is/issues/7) describe cómo comprobarla.
